# Robert Garcia Portfolio — Image Guide

Put your own images in an `images/` folder next to `index.html`, using these exact filenames (or edit the `src` paths in `index.html` if you'd rather use different names):

| Filename                     | Used for                          | Suggested size |
|-------------------------------|------------------------------------|-----------------|
| images/slider-1.jpg           | Hero slider, photo 1               | 500×500px (square) |
| images/slider-2.jpg           | Hero slider, photo 2               | 500×500px (square) |
| images/slider-3.jpg           | Hero slider, photo 3               | 500×500px (square) |
| images/about.jpg              | About Me photo                     | 500×500px (square) |
| images/project-web.jpg        | "Nova Finance Website" project     | 500×350px |
| images/project-app.jpg        | "Fitly Mobile App" project         | 500×350px |
| images/project-branding.jpg   | "Cedar & Co Identity" project      | 500×350px |
| images/project-graphic.jpg    | "Summer Festival Posters" project  | 500×350px |
| images/testimonial-1.jpg      | Testimonial avatar 1               | 100×100px |
| images/testimonial-2.jpg      | Testimonial avatar 2               | 100×100px |
| images/testimonial-3.jpg      | Testimonial avatar 3               | 100×100px |

The slider (`#slider`) auto-advances every 5 seconds and needs at least 3 images to be meaningful — add more `<img>` tags inside `.slider` in `index.html` if you want more than 3, the JS will pick them up automatically (no changes needed in `script.js`).

Files:
- `index.html` — markup
- `style.css` — all styling
- `script.js` — slider, scroll-triggered progress bars, project filtering, nav, mobile menu, form
